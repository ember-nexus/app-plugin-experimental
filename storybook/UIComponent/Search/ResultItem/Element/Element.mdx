# `ember-nexus-ui-search-result-item-element`

A single result item used to display a specific element. It is used as a link to the element's detail page, and should
display its thumbnail, name and description.

It does not use the element's card here, as the name and description should contain the search query in a highlighted
manner.

As with all result items, the item can be selected via <kbd className="kbd kbd-sm">tab</kbd> and be triggered via
<kbd className="kbd kbd-sm">space</kbd> or <kbd className="kbd kbd-sm">enter</kbd>.
